# Vortex Collections API

No Render, configure o serviço apontando para esta pasta:

- **Root Directory:** `backend`
- **Build Command:** `npm install`
- **Start Command:** `npm start`

Crie um Postgres no Render, execute `schema.sql` e adicione as variáveis do `.env.example` em **Environment**. Nunca coloque `MP_ACCESS_TOKEN` no frontend.
